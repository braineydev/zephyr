# Public media

This directory contains temporary, licensed stock images for the Phase 2 reconstruction preview. They are not images of Zephyr Westlands or GY Group property. Every image is captioned in the preview, and source, contributor, Pexels page, license check date, local dimensions, crop, and owner approval are listed in `docs/ASSET_MANIFEST.csv` and `docs/ASSET_CREDITS.md`.

The owner authorized online temporary substitutes on 2026-11-23 with the instruction: “find replicas and substitutes of the actual assets you want online and we will use them for now, i have sent an invoice to the zephyr team, when i get the real assets we will substitute them”. The actual Zephyr source images remain marked missing; replace these local files and update the manifest when the authorized originals arrive.

Pexels license page checked 2026-11-23: https://www.pexels.com/license/. The license permits website use and modification, with no attribution required; it also prohibits implying endorsement by people or brands appearing in images. The preview explicitly labels all stock images as temporary illustrative substitutes.
